# Plano: aplicação real com autenticação e persistência

1. Criar a API NestJS mínima com Prisma, autenticação JWKS e endpoints de
   catálogo/empréstimo. Relacionado a CA-02, CA-04 e CA-05.
2. Tornar o seed idempotente e popular o tenant com equipamentos. Relacionado
   a CA-06.
3. Criar autenticação Supabase e tela de login no frontend. Relacionado a
   CA-01.
4. Substituir o estado mockado por chamadas à API. Relacionado a CA-03.
5. Validar build/testes e publicar branches coordenadas.

Restrições: ADR-001, regras de segurança, migrations e secrets dos dois
repositórios.
